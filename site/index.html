Comment ça marche

Cette page est la télécommande. Le montage se fait sur un ordinateur de GitHub, gratuitement, pendant quelques minutes. Quand il a fini, le clip apparaît dans « Mes clips », prêt à être regardé et téléchargé. Rien ne s'installe chez toi.

Créer la clé d'accès (une seule fois, 2 minutes)

La clé autorise cette page à lancer une fabrication à ta place, uniquement sur le dépôt clip-usine.

  1. Ouvre la page de création de clé de GitHub.
  2. Nom : clip-usine. Expiration : 90 jours.
  3. « Repository access » : choisis Only select repositories, puis clip-usine.
  4. « Permissions », puis « Repository permissions » : mets Actions sur Read and write. Ne touche à rien d'autre.
  5. Clique « Generate token », copie la clé (elle commence par github_pat_) et colle-la dans le Studio.

La clé reste dans ton navigateur ; elle n'est envoyée qu'à GitHub. Si tu la perds ou si quelqu'un la voit, supprime-la sur la même page de GitHub et crées-en une autre.

Sans clé : demander à Claude

Dans la conversation Claude où l'outil a été créé, écris par exemple : « Clippe ce lien en montage best-of, 4 temps forts, titre : … ». Claude lance la fabrication et te dit quand le clip est en ligne.

Activer le radar (facultatif)

  1. Sur dev.twitch.tv/console, crée une application (nom libre, adresse de redirection http://localhost).
  2. Copie le « Client ID » et génère un « Client Secret ».
  3. Dans le dépôt GitHub : Settings, Secrets and variables, Actions, puis ajoute TWITCH_CLIENT_ID et TWITCH_CLIENT_SECRET.

Règles à respecter

  1. Ne clippe que ce qu'on t'autorise : le brief d'une campagne qui cite la source, ou l'accord écrit du streamer.
  2. Pas de spoiler : ni fin du jeu, ni cinématique isolée.
  3. Clip rémunéré : mention de partenariat visible et case « contenu de marque » cochée dans l'appli.
  4. Jamais d'achat de vues.
